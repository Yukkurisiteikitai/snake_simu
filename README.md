# 蛇シミュレーション - 学習プロジェクト

「蛇がどうやって前進するのか」をプログラムで再現して、学ぶプロジェクトです。

**高校数学が怪しくても大丈夫。** ステップバイステップで学べます。

---

## 🐍 このプロジェクトの目標

蛇が地面に接して左右に波を作ることで、なぜ前進できるのか。

この物理を、プログラムで再現します。

```
筋肉活動 → 関節角 → 体の形 → 摩擦 → 前進！
```

## 🔧 よく質問されること

### Q: Phase 1 と Phase 2 の違いは？

**Phase 1**
- 蛇の頭が固定
- 蛇は形を変えるが位置は変わらない
- FK だけで十分

**Phase 2**
- 蛇の頭が移動
- 異方性摩擦を加える
- 蛇が前進する

### Q: 3D にできる？

はい。この 2D の技術を拡張すれば 3D もできます。

ただし実装が複雑になるので、最初は 2D で十分。

### Q: 現実の蛇をシミュレートできる？

このモデルは「最小限の現実的なシミュレータ」です。

より現実的にするには：
- 筋肉の詳細なモデル（Hill型筋肉モデル）
- 複雑な環境（障害物、傾斜など）
- より精密な接触計算

などを加えます。

### Q: パラメータを変えたら蛇が動かなくなった

よくあります。特に摩擦係数が大事です：

```python
# これは動く
c_forward = 1.0
c_lateral = 10.0

# これだと動かない
c_forward = 10.0
c_lateral = 10.0
# ← c_lateral と c_forward が同じだと摩擦が等方的
```

`c_lateral > c_forward` を保ちましょう。

## 💡 学習のコツ

1. **わからないなら、数式から始めない**
   - 絵や動画で概念を理解する
   - その後、式を見る

2. **数値で試す**
   - 理論だけでなく、パラメータを変えて実験
   - 「こう変わるんだ」という感覚を持つ

3. **フレームバイフレームで追う**
   - アニメーションを一時停止
   - 蛇がどう動いているか観察

4. **モジュールの責任を理解する**
   - CPG は「何を出力するのか」
   - FK は「何を入力して何を出力するのか」
   - 各部分の役割を把握
